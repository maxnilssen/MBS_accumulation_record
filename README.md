This repository contains the code used to develop the Mount Brown South annual snow accumulation record (873-2017 CE).

Nilssen, M. T., Vance, T. R., Christoffersen, P., Cook, S., Criscitiello, A. S., and Abram, N. J.: High centennial-scale variability in an East Antarctic snow accumulation record spanning the last millennium, EGUsphere [preprint], https://doi.org/10.5194/egusphere-2026-4880, 2026.
